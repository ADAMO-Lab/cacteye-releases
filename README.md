# Cacteye releases

Installers and update files for Cacteye (macOS and Windows). Download the newest from [Releases](https://github.com/ADAMO-Lab/cacteye-releases/releases/latest).

macOS: open the .dmg and drag Cacteye to Applications. Windows: run the setup .exe (SmartScreen: More info, then Run anyway).

Installed copies check here for updates and offer them in one click.
